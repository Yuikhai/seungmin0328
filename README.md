# 부산물마켓

부산 지역의 수산부산물·폐어구·폐플라스틱을 연결하는 모바일형 자원순환 플랫폼입니다.

## GitHub Pages로 공유하기

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 `index.html`과 `assets` 폴더를 저장소에 업로드합니다.
   - 반드시 `assets` 폴더 전체와 안의 PNG 파일 13개도 함께 올려야 합니다.
   - 저장소 구조는 `index.html`과 `assets`가 같은 위치에 있어야 합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`로 설정하고 저장합니다.
6. 잠시 후 생성된 `https://사용자명.github.io/저장소명/` 주소로 접속합니다.

## 포함 기능

- 수산부산물·폐어구·폐플라스틱 검색
- 맞춤 부산물 추천
- 부산물 상세 및 재활용 활용법
- 예약 및 예약 취소
- 부산물 등록·사진 첨부·내 등록품 삭제
- 주민 커뮤니티 게시물·사진·댓글·좋아요·공유
- 포인트 적립 및 기부
- 5분 상담형 로컬 채팅

현재 데이터 저장은 브라우저의 로컬 저장소를 사용하는 MVP 방식입니다.

## 이미지가 안 보일 때

GitHub 저장소에서 `assets` 폴더를 열었을 때 PNG 파일들이 실제로 올라갔는지 확인하세요. `index.html`만 업로드하면 사진은 표시되지 않습니다. 업로드 후 GitHub Pages 주소에서 `Ctrl + F5`로 새로고침하세요.
